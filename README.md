# سلة التوفير

تطبيق ويب بسيط (يشتغل على الجوال واللابتوب) لمقارنة أسعار المقاضي في السعودية:

- **قائمتي**: أضف أغراضك، واضغط «ابحث» لكل متجر (أمازون، نون، بنده، العثيم، الدانوب، كارفور، التميمي، لولو…) وسجّل السعر.
- **المقارنة**: يحسب أرخص متجر لكل غرض، وأرخص متجر للقائمة كاملة، وكم توفّر، ويطلع لك قائمة جاهزة للواتساب.
- **المتاجر والعروض**: روابط لكل المتاجر ومجلات العروض (D4D، كليك فلاير) والكوبونات.

البيانات تنحفظ في متصفحك فقط. افتح `index.html` في أي متصفح، أو انشره عبر GitHub Pages.
